# Сопровождение upstream

[English](upstream.en.md)

Репозиторий хранит редактируемые копии skills; запуск не требует загрузки другого репозитория.
Исходная версия Matt: `a496f5513d4a4cf889bc48e189e579f4b0bdf6aa`.
Начальные локальные адаптации получены через [ai-first-platform](https://github.com/KirillSachkov/ai-first-platform/commit/53c0b946506b41839e255806144c3289680061c8).
Это не означает побайтного совпадения каждого файла с Matt.

## Выбор обновления

1. Создайте issue: изменение upstream, ожидаемая польза, границы и проверки.
2. Получите прежний исходник и предлагаемую новую версию в отдельных временных копиях.
3. Сравните три версии: прежний upstream, новый upstream и наш текущий файл.
4. Выберите полезные изменения и сохраните локальную политику. Учтите references и native metadata соответствующего skill.
5. Запишите источник и адаптации, выполните проверки и проведите результат через PR.

Не заменяйте локальный каталог skills новым каталогом upstream целиком.
При частичном обновлении запишите исключения по skills в `.agents/skills/README.md`.
Сохраняйте исходную общую версию, пока полное обновление не учтёт каждый заимствованный файл.
Обновляйте directory hashes после изменений; они подтверждают идентичность, а не качество.
Здесь нет запланированной синхронизации, update bot, submodule или установщика.

## Локальные адаптации

Начальные адаптации касаются доменных имён, проектных полномочий, committed review, проверки исправлений и доставки PR.
Этот репозиторий добавляет выбор языка и удаляет факты конкретного приложения.
`ship` создан локально; он не скопирован у Matt.
README skills содержит runtime pointers, уведомления и идентификаторы содержимого.
При переносе upstream-предложений сохраняйте один источник проектной политики.
