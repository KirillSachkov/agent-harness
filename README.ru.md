# Agent Harness

[English](README.en.md) · [Выбор языка](README.md)

Личный рабочий пример Кирилла Сачкова.
Он начинается с небольшого процесса и развивается через реальные задачи и эксперименты.

## Начало

Откройте репозиторий в coding agent, который умеет читать проектные skills.
Попросите применить `setup-matt-pocock-skills` и выберите английский или русский.
Настройка проходит как беседа. Она сохраняет существующие настройки и показывает предлагаемые изменения перед записью.

Оба языка поддерживают одинаковый процесс.
Текущая настройка владельца — русский; setup позволяет выбрать любой из двух языков.
Skills и агентские инструкции остаются английскими.
README, процесс, границы, сопровождение upstream и план экспериментов имеют равные версии EN/RU.

## Работа

1. Обсудите результат и подготовьте issue. Полная spec нужна по сложности задачи.
2. Явно выберите `implement` для ограниченной задачи или `implement-spec` для spec и её tickets.
3. Работайте в отдельном worktree. Выполните проверки и независимое Standards/Spec review.
4. Исправьте дефекты и получите независимую проверку исправлений.
5. Примените `ship`: подготовьте PR, дождитесь текущего CI и передайте результат владельцу.
6. Владелец принимает результат и отдельно разрешает merge проверенного head: в PR или в сообщении.

[Карта процесса](docs/process.ru.md) объясняет баги, идеи, человеческие проверки и доставку.
Обязательные правила агента находятся в [AGENTS.md](AGENTS.md) и его условных ссылках.

## Состав

- 27 редактируемых skills на основе Matt Pocock и локальный `ship`.
- Native metadata и ссылка `.claude/skills` на `.agents/skills`. Claude Code и Codex читают `AGENTS.md` сами, поэтому `CLAUDE.md` нет.
- Проектные правила требований, worktree, тестирования, человеческого участия и доставки.
- `python3 scripts/check.py` для структурной проверки без сторонних пакетов Python.

Репозиторий — пример для развития. Одинаковое поведение всех coding agents пока не подтверждено.
Здесь нет приложения или автоматического установщика.

## Развитие

Прочитайте [границы](docs/requirements.ru.md), [сопровождение upstream](docs/upstream.ru.md) и [план экспериментов](docs/experiments.ru.md).
Skills хранятся как редактируемые копии из зафиксированной версии.
Обновления выбираются и проверяются вручную; автоматической синхронизации нет.

Структурные проверки и независимое ревью не доказывают соблюдение процесса живым агентом.
Сравнительный эксперимент ещё не установил преимущество этого процесса.
